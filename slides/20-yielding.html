Promise chains starve too

async function processAll (items) {
  for (const item of items) {
    await transform(item)   // resolves immediately? then it never yields
  }
}
// 10,000 cache hits = 10,000 microtasks back to back:
// timers, I/O callbacks and new connections all wait

await yields to the microtask queue, not the event loop. Microtasks run to exhaustion. Only a macrotask (setImmediate) lets I/O in.

Cooperative yielding

import { maybeYield } from '@nxtedition/yield'

for (const row of db.prepare('SELECT * FROM huge_table').iterate()) {
  processRow(row)
  const p = maybeYield()   // null until 40 ms have passed
  if (p) await p           // then give the event loop a turn
}

How it works

The check: a clock read
let yieldTime = performance.now()
const budget = 40                // ms between yields

function shouldYield () {
  return performance.now() - yieldTime >= budget
}

function maybeYield () {
  // null on the fast path: no Promise, no await
  return shouldYield() ? doYield() : null
}
The yield: one setImmediate for all waiters
const queue = []
let scheduled = false

function doYield () {
  const p = new Promise((resolve) => queue.push(resolve))
  if (!scheduled) {
    scheduled = true
    setImmediate(drain)          // I/O runs before this
  }
  return p
}

function drain () {
  scheduled = false
  yieldTime = performance.now()  // a fresh budget
  for (const resolve of queue.splice(0)) resolve()
}

Yielding lets you use sync APIs (readFileSync, DatabaseSync) on the main thread without starving the loop. Do real work, yield, repeat.

Simplified from @nxtedition/yield: the real one also takes a callback + opaque instead of a Promise, and drains in budgeted slices.
