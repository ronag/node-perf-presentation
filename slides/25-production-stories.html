…and a few that bit us

What happenedLesson
A plain object used as a lock map never deleted keysV8 caps an object at 2²³−1 properties: RangeError, a 45-hour outage. Use a Map and delete.
glibc malloc kept GiBs of idle memory in arenasPreload mimalloc. Its purge delay trades RSS (+55 MiB) for throughput (+51%).
WASM SIMD for a byte scanLost to a plain JS loop (30 vs 19 ns) once copying the input in was counted.
