When to optimize

Hot pathsCode that runs millions of times per second
High scale100+ servers: every % matters
Latency-sensitiveReal-time, trading, media
ConstrainedEdge, IoT, memory-bound containers

Don't optimize code that runs once per request on two servers. Measure first, then decide.

Complexity is the enemy

Optimized code and distributed systems are both harder to reason about, debug and maintain. Choose the lesser evil, and measure before you choose.
