Compute is cheap. Memory is not.

RAM sets your instance size and your bill. Every live byte is something the GC traces and the CPU cache misses.

You pay for RAMInstances are sized by memory; the cores come along. Fewer bytes per request means fewer, smaller machines.
The GC traces every live byteMajor GC cost grows with the live heap, not with the garbage. Big heaps mean long pauses.
The CPU waits on memoryA cache miss costs ~100× an L1 hit. Dense data is fast data.

Every byte you don't allocate is compute you don't spend.

⏱ 1:15. The thread through the talk: we optimize bytes as much as nanoseconds. Fewer bytes means a smaller heap, less GC, fewer cache misses, smaller instances.
