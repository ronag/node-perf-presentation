≥ 32 chars: SIMDCopy into linear memory as UTF-8, then classify 16 bytes at a time with nibble lookup tables and find ?, // and % with bitmasks.

Copy as UTF-8, not latin1: latin1 keeps only the low byte, so U+012F would turn into /. Without WebAssembly or SIMD, fall back to the regex parser.
