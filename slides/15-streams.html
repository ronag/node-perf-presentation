Streams

Backpressure and chunk size

stream.setDefaultHighWaterMark

import { setDefaultHighWaterMark } from 'node:stream'

// objectMode = false: all byte streams
setDefaultHighWaterMark(false, 256 * 1024)
Bigger highWaterMarkFewer backpressure stalls, fewer callbacks and syscalls per byte on sockets and files.
Trade-off: memoryEach stream buffers more. With thousands of concurrent streams it adds up.

Default: 64 KiB since Node 22 (16 KiB before; still 16 KiB on Windows). In-process pipelines barely care; small socket writes do (see the HTTP chapter).
