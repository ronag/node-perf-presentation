Choose your durability deliberately

default: rollback journal, synchronous=FULL
journal_mode=WAL, synchronous=FULL
journal_mode=WAL, synchronous=NORMAL
journal_mode=WAL, synchronous=OFF

NORMAL in WAL mode never corrupts; a power cut may lose the last commits. OFF is for data you can rebuild: caches, scratch tables.

Batch writes: 1,000 rows per transaction (WAL + NORMAL) is 1.36 µs per row.

Contending writers: seconds-long stalls

One writer per file: eight Workers on one file queue in SQLite's busy handler. Throughput moves a little either way; the tail doesn't.

A pragma recipe for a cache

PRAGMA journal_mode = WAL;          -- readers never block the writer
PRAGMA synchronous = OFF;           -- rebuildable data: no fsync
PRAGMA wal_autocheckpoint = 10000;  -- checkpoint less often
PRAGMA mmap_size = 268435456;       -- read through the page cache
PRAGMA cache_size = -32768;         -- KiB of SQLite page cache
PRAGMA max_page_count = …;          -- hard size cap → SQLITE_FULL → evict
BEGIN IMMEDIATETake the write lock up front. A deferred transaction that upgrades later can deadlock with another writer.
Read the pragma backjournal_mode = OFF is silently refused unless you open with { defensive: false }.

Keep maintenance off the event loop

main thread, one statement
① batches of 500, yield in between
② a Worker with its own connection
① Break it into batches and yield
import { setImmediate } from 'node:timers/promises'

const del = db.prepare(`DELETE FROM cache WHERE k IN
  (SELECT k FROM cache WHERE expires < ? LIMIT 500)`)
while (del.run(now).changes > 0) {
  await setImmediate()   // let I/O in
}
② Move it to a Worker
// maintenance.mjs runs in a Worker, own connection
const db = new DatabaseSync('cache.db', { timeout: 1000 })
db.prepare('DELETE FROM cache WHERE expires < ?').run(now)
db.exec('PRAGMA wal_checkpoint(TRUNCATE)')

The total work stays about the same, 140–160 ms: it's spread out, not removed. Combine them: in WAL mode the Worker doesn't block readers, but it still holds the write lock, so batch there too.
