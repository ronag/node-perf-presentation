Deferred Work

Do less now, do more later

Do work, but later

O(1) inline: a Set
const requests = new Set()

function onRequest (req) {
  // per request: hash,
  // a closure and a listener
  requests.add(req)
  req.on('close', () => {
    requests.delete(req)
  })
}
O(n) deferred: array + sweep
const requests = []

function onRequest (req) {
  requests.push(req)  // one push
}

function sweep () {
  for (let n = 0; n < requests.length;) {
    if (requests[n].closed) swapRemove(requests, n)  // O(1)
    else n++
  }
}
setInterval(sweep, 2000)

An O(n) sweep every 2 s can be cheaper than bookkeeping on every request, but closed requests stay alive up to 2 s longer and may get promoted. Measure both.

Off-peak scheduling

cron('02:00', () => {
  compactCaches()
  rotateLogs()
  globalThis.gc()   // a full collection when nobody is waiting (--expose-gc)
})

You can't avoid expensive work, but you can choose when some of it happens: compaction and cleanup run off-peak. A forced GC doesn't stop V8 collecting at peak.
