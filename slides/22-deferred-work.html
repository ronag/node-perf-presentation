Deferred Work

Do less now, do more later

Do work, but later

O(1) inline: a Set
const requests = new Set()

function onRequest (req) {
  // per request: hash,
  // a closure and a listener
  requests.add(req)
  req.on('close', () => {
    requests.delete(req)
  })
}
O(n) deferred: array + sweep
const requests = []

function onRequest (req) {
  requests.push(req)  // one push
}

function sweep () {
  for (let n = 0; n < requests.length;) {
    if (requests[n].closed) swapRemove(requests, n)
    else n++
  }
}
setInterval(() => scheduler.run(sweep, 'lowest'), 2000)

An O(n) sweep at 'lowest' priority every 2 s beats O(1) overhead on every request.

Off-peak scheduling

cron('02:00', () => {
  compactCaches()
  flushLogs()
  global.gc()   // a full collection when nobody is waiting (--expose-gc)
})

You can't avoid expensive work, but you can choose when it happens. GC and cleanup run when you decide, not in the middle of a request.
