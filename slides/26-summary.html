Key takeaways

  1. Measure first, on the hardware you ship on. Then doubt the measurement.
  2. Build Node for your CPU and workload. -march, PGO, pointer compression: +28% HTTP req/s and −63% RSS on the same source
  3. Compute is cheap, memory is not. Every allocation is future GC work: reuse, pool with bounds, keep state dense.
  4. Sync beats async when the answer is ready. An await costs ~100 calls; sync I/O is 12–190× faster.
  5. Don't block the loop. await yields to microtasks, not I/O: yield on a budget and prioritize.
  6. SQLite: choose durability, batch, shard writers. Up to 159× per row; +73% with 8 shards.
  7. Workers + reusePort + shared memory. A ring buffer moves 34× more messages than postMessage.
  8. A few flags go a long way. --max-semi-space-size, Buffer.poolSize, UV_THREADPOOL_SIZE: one line each.
