Bitmap State

Pack flags and counters into a single integer

The pattern

Object properties: state spread out
class State {
  objectMode = false
  ended      = false
  reading    = false
  flowing    = false
  destroyed  = false
  // … 25 more booleans
}
// one field (8 bytes) per flag
Bitmap: all state in one integer
const kObjectMode = 1 << 0
const kEnded      = 1 << 1
const kReading    = 1 << 3
const kDestroyed  = 1 << 4

let state = 0     // one Smi, stay below bit 31
state |= kReading          // set
state &= ~kReading         // clear
state & kReading           // test

Compound tests are free

const kDone = kEnded | kDestroyed | kClosed | kErrored

if (state & kDone) return   // 1 AND, 1 branch

// vs 4 loads and 4 branches:
if (s.ended || s.destroyed || s.closed || s.errored) return

Counters in the low bits

flags · 1 bit eachcounter · 8 bits 
const kCounterMask = 0xff     // bits 0–7 (max 255)
const kFlag        = 1 << 8   // flags start above the counter

state++                // increment: no shift, no mask
state & kCounterMask   // read the counter
state & kFlag          // flags are unaffected

Reference counts, queue depths, pending I/O: all packable next to the flags.
